# Jade Horizon — A Mahjong Odyssey

A 3D Mahjong solitaire game that runs in the browser. It has an 80-level campaign, an original 8-chapter story, quick play, a guided tutorial, saves, badges and 50 achievements. Everything is procedural: tile art, landscapes and audio are generated in code, so the game ships as **one self-contained HTML file** with no asset files.

## Run it

```bash
# repo root: games/jade-horizon
npm install
npm run dev        # local dev server with hot reload
npm run build      # typecheck + single-file build -> dist/index.html
npm test           # rules engine + content tests (vitest)
```

`dist/index.html` opens directly from disk or from any static host (Vercel, Netlify, Cloudflare Pages).

## Modes

| Mode | What it is |
|---|---|
| **Tutorial** | 12 coached steps: free tiles, matching, blocked tiles, hint, undo, shuffle, camera, combos, and a glossary of the special tiles. |
| **Campaign** | 80 fixed levels across 8 realms (10 each, the 10th is a realm boss). Uses a winding level map in the style of mobile puzzle games, and each level earns up to 3 stars. A new mechanic arrives in each realm and stays for the rest of the campaign. |
| **Quick Play** | Choose 1 of 5 difficulty tiers, 1 of 24 boards (or Random) and 1 of 8 realms, then play. |
| **Story** | *The Lantern of Eight Winds*: 8 chapters of dialogue and 9 story boards. Each realm starts drained to grey, and the board's color returns as you clear it. In the finale you name the forgotten Ninth Wind, and that name is carved into the 145th tile and appears in your journal. |

### Difficulty tiers (Quick Play)
Zen · Easy · Normal · Hard · Master. Each tier changes the following:
- whether matching sets are unique pairs or classic four-of-a-kind
- how much of the board is under mist
- how many hints, shuffles and undos you get
- whether the board has locks and bombs
- whether there is a time limit

### Mechanics
- **Mist**: a blocked tile's face stays hidden until the tile is free.
- **Gold pairs**: worth bonus points. Some levels are won by collecting every gold pair.
- **Chains**: a tile unlocks after a set number of matches.
- **Bombs**: a fuse burns down with every match. Pair the bombs before the fuse reaches zero.
- **Sand clock**: the level has a time limit.

Every deal is **guaranteed solvable**. The board is generated by reverse play, and lock counts and bomb fuses are checked against that solution. Shuffle re-deals the remaining tiles into a new solvable arrangement. Hint runs a bounded search and points to a move that keeps the board winnable.

### Stars (campaign)
★ Win · ★ Finish under par time · ★ Win without hints, undos or manual shuffles.

## Saving
- **Session save**: the game autosaves after every move, when you pause, when you switch tabs and when you close the page. **Continue** on the title screen resumes the autosave.
- **3 manual save slots**, saved from the pause menu and loaded from **Load Game**.
- **Profile**: stores stars, best scores and times, badges, achievements, stats, story progress and settings.
- **Export / import** the whole save as JSON in Settings. Reset is also in Settings.

Saves use `localStorage`. If storage is unavailable, the game keeps saves in memory for the session.

## The 8 realms
Blossom Valley · Bamboo Highlands · Lantern Harbor · Desert of Echoes · Frostpeak Monastery · Autumn Canyons · Volcanic Forge · Celestial Isles.

Each realm is a procedural low-poly landscape with its own sky, lighting, landmark and particles: petals, fireflies, dust, snow, leaves, embers or stars. The renderer adds bloom, color grading and camera flights between screens.

## Code map
```
src/
  engine.ts        rules: free-tile topology, solvable deal, reshuffle, hint solver
  layouts.ts       24 board layouts (16–144 tiles)
  levels.ts        80-level campaign generator, quick-play tiers, tutorial level
  story.ts         cast, 8 chapters, dialogue, memory fragments
  game.ts          one play session: input, scoring/combos, mechanics, autosave
  boardview.ts     3D tile meshes + animations (deal-in, match, flip, shuffle)
  world.ts         procedural realms: terrain, water, trees, landmarks, particles
  stage.ts         renderer, post-processing, camera flights, tween system
  faces.ts         canvas-painted tile faces
  audio.ts         synthesized SFX + generative pentatonic ambience
  achievements.ts  50 achievements + 15 badges
  save.ts          profile + snapshot persistence
  app.ts           screens, HUD, dialogue, tutorial coach, progression
tests/engine.test.ts
```
